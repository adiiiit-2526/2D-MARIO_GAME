**FULL USE CASE SPECIFICATIONS**

**PROJECT: 2D GAME ENGINE**

**Use Case 1: Create New Game Project**

| **Use Case Name**   | Create New Game Project                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Primary Actor**   | Game Developer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Stakeholders**    | Game Developer, Game Engine System                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Preconditions**   | The game engine is installed and running. The developer has permission to create files/projects.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Postconditions**  | A new game project is created with the required folders, configuration files, and default scene.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Trigger**         | The developer selects "Create New Project" from the game engine.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Main Flow**       | 1\. The developer launches the 2D Game Engine. <br>2\. The developer selects Create New Project. <br>3\. The system displays the project creation form. <br>4\. The developer enters the project name and selects a location. <br>5\. The developer confirms the project creation. <br>6\. The system validates the project details. <br>7\. The system creates the project directory and required files. <br>8\. The system creates a default scene. <br>9\. The system opens the new project in the editor. <br>10\. The system displays a confirmation that the project was created successfully. |
| **Alternate Flows** | A1. Invalid Project Name <br>1\. The developer enters an invalid or empty project name. <br>2\. The system displays an error message. <br>3\. The developer enters a valid project name. <br>4\. The system continues from Step 5 of the main flow. <br><br/>A2. Project Location Already Contains a Project <br>1\. The selected location already contains a project with the same name. <br>2\. The system informs the developer that the project already exists. <br>3\. The developer selects another location/name. <br>4\. The system continues from Step 5 of the main flow.                  |

**Use Case 2: Add and Manage Game Object**

| **Use Case Name**   | Add and Manage Game Object                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Primary Actor**   | Game Developer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Stakeholders**    | Game Developer, Game Engine System, Game Designer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Preconditions**   | A game project is open and a scene is available in the editor.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Postconditions**  | A game object is added to the scene with its selected properties/components and can be saved as part of the scene.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Trigger**         | The developer selects Add Game Object from the editor.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Main Flow**       | 1\. The developer opens a scene. <br>2\. The developer selects Add Game Object. <br>3\. The system displays available object types. <br>4\. The developer selects an object type, such as Player, Enemy, Sprite, or Platform. <br>5\. The system creates the selected object in the scene. <br>6\. The developer selects the object's position and size. <br>7\. The developer adds or modifies components such as Sprite, Collider, or Physics. <br>8\. The system updates the object properties. <br>9\. The developer saves the scene. <br>10\. The system stores the game object and its properties in the scene file.                                                                                                        |
| **Alternate Flows** | A1. Invalid Object Position <br>1\. The developer places the object outside the valid scene boundaries. <br>2\. The system detects the invalid position. <br>3\. The system displays a warning or adjusts the object to a valid position. <br>4\. The developer confirms the position. <br>5\. The system continues with Step 8 of the main flow. <br><br/>A2. Missing Required Component <br>1\. The developer attempts to use a feature requiring a specific component. <br>2\. The system detects that the required component is missing. <br>3\. The system displays a message asking the developer to add the required component. <br>4\. The developer adds the component. <br>5\. The system continues with the main flow. |

**Use Case 3: Run and Test Game**

| **Use Case Name**   | Run and Test Game                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Primary Actor**   | Game Developer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Stakeholders**    | Game Developer, Game Engine System, Game Tester/Player                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Preconditions**   | A game project exists, the scene is saved, and the project contains the required game assets and objects.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Postconditions**  | The game is executed successfully, or errors are reported to the developer.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Trigger**         | The developer selects the Run/Play button in the game engine.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Main Flow**       | 1\. The developer opens the game project. <br>2\. The developer saves the current scene. <br>3\. The developer selects Run/Play. <br>4\. The system validates the project and scene. <br>5\. The system loads the required assets. <br>6\. The system initializes the game objects and physics system. <br>7\. The system starts the game loop. <br>8\. The game window is displayed. <br>9\. The developer interacts with the game to test its functionality. <br>10\. The system processes input, physics, collisions, and rendering. <br>11\. The developer selects Stop after testing. <br>12\. The system stops the game and returns to the editor. |
| **Alternate Flows** | A1. Missing Asset <br>1\. During validation, the system detects that a required asset is missing. <br>2\. The system displays an error message identifying the missing asset. <br>3\. The game does not start. <br>4\. The developer adds or restores the missing asset. <br>5\. The developer runs the game again. <br><br/>A2. Runtime Error <br>1\. A runtime error occurs while the game is running. <br>2\. The system detects the error. <br>3\. The system displays the error details in the console/debug window. <br>4\. The developer stops the game. <br>5\. The developer fixes the error and runs the game again.                           |
