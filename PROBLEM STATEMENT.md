**PROBLEM STATEMENT**

**Project : 2D Game Mario Style with Multiplayer**

Traditional Mario-style platform games are mainly designed for a single player, which limits interaction and collaboration between players. Players cannot play together in the same game environment, compete with each other in real time, or help each other complete levels. This reduces the social and interactive experience of the game, especially when multiple players are available on the same Wi-Fi network.

The proposed system aims to solve this problem by developing a Wi-Fi-based multiplayer Mario-style game in which multiple players can connect their devices over the same Wi-Fi network and participate in the same game session. Each player will control their own character while sharing the same game environment. The system will synchronize player movements, actions, scores, collisions, and game events between connected devices in real time.

The multiplayer system will allow players to join a game, communicate their game actions through the Wi-Fi network, and compete or cooperate to complete levels. This approach will enhance the gaming experience by introducing real-time interaction while maintaining the basic platforming elements such as jumping, collecting coins, avoiding obstacles, and defeating enemies.
